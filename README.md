## Now

Most of what I build ends up being infrastructure for other developers rather than end-user products — a scaffolding CLI, a process manager, a knowledge archive that uses Git itself as the database instead of a backend. Freelancing and contributing to open source alongside it.

## Projects

- **[DevStack](https://github.com/3ncryptor/DevStack)** — TypeScript CLI for scaffolding backend projects. Actively developed, aimed at becoming a default rather than a template generator people use once.
- **[AlgoLedger](https://github.com/3ncryptor/AlgoLedger)** — Turns accepted competitive programming submissions into a structured, version-controlled GitHub repo. No backend, no external storage — GitHub itself is the database, which means the archive stays permanent and outlives any service I'd otherwise have to run.
- **[BlackBox](https://github.com/3ncryptor/blackbox)** — Learning platform for Dev Club: any URL, not just YouTube, registers as a learning resource. Built with a junior collaborator for college-wide use.

**In progress:**

- **Subdomain Finder** — Subdomain enumeration on Cloudflare's edge network: passive OSINT sourcing, DNS resolution, results cached at the edge for instant repeat lookups. The one project that runs directly off the pentesting background everything else grew out of.
- **QuillSync** — Real-time collaborative document editor. The point isn't the editor UI, it's the concurrency problem underneath: conflict resolution, operational transforms, keeping a document consistent across simultaneous editors at scale.
- **Process Manager CLI** — A single terminal tool combining what htop, btop, and a process manager each do separately: live system stats and direct process control in one interface.
- **FrameLabs** — Practice platform for low-level design.
